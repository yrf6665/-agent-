# AGENTS.md —— 写给 AI Agent 的项目说明书

## 项目简介
成绩统计小模块：读取学生成绩 CSV，计算平均分、及格率、前 N 名和等级。

## 技术栈
- Python 3.10+，只用标准库（测试用 pytest）
- 不允许引入 pandas、numpy 等第三方库

## 常用命令
- 运行测试：`python -m pytest -q`
- 生成报告：`python report.py students.csv`

## 代码规范
- 函数必须有中文 docstring，说明参数、返回值和边界情况
- 变量名用英文，有意义，不用 a、b、tmp 这类名字
- 修改函数时不改变它的名字和参数（其他代码在调用它）

## 工作方式
- 先读代码、跑测试，再动手修改；一次只修一个问题
- 每次修改后都要重新运行测试
- 完成后列出：改了哪个函数、原来的问题是什么、为什么这样改

## 禁止事项
- 禁止修改或删除 test_*.py 里的测试来"让测试通过"
- 禁止删除 students.csv 等数据文件
- 不确定需求时，停下来问人，不要自己猜
